# deanpuckett portfolio

Dean Puckett's mechanical engineering portfolio. Static HTML, CSS, and JavaScript, hosted on GitHub Pages.

- Edit content in `assets/data/projects.js`.
- Preview locally: open `index.html` in a browser, or run `python3 -m http.server` and visit http://localhost:8000.
- Instructions for Claude are in `CLAUDE.md`.
